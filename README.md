# Vervant public product site

- Website: https://vervant-pdf-api.deed.page/
- Developer guides: https://vervant-pdf-api.deed.page/guides/
- HTML invoice template: https://vervant-pdf-api.deed.page/examples/invoice-template.html

This repository contains only the public static marketing and developer-resource website. The hosted Vervant API is still in private-beta preparation and is not publicly available. Do not send production, personal or confidential documents to the prototype.

Vervant is building a focused HTML-to-PDF API for SaaS backends, with reusable templates, API keys, usage quotas and restricted browser rendering.

## Security and data status

This is a prototype and product information site only. The hosted API is not publicly available. The current rendering prototype disables page JavaScript and blocks page network requests, but its Chromium process sandbox is disabled in the current constrained runtime. These controls are not a substitute for a separately isolated renderer and OS/container confinement. Do not send confidential or production documents.
