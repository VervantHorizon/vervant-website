SECURITY-MINDED RENDERING

Untrusted HTML deserves
careful boundaries.

Rendering user-controlled markup can expose infrastructure when browser automation is unrestricted. Vervant's current renderer disables page JavaScript and blocks outbound and local network requests during PDF generation.

01JavaScript disabledDocument markup is rendered without executing page scripts.

02Remote requests blockedExternal URLs and local network requests are blocked in the renderer.

03Scoped credentialsAPI keys can be created and revoked independently.

04Quota controlsMonthly usage is reserved atomically against plan limits.
