WORKFLOW

Simple rules, explicit checks.

01 · INSPECTIdentify the object

Read the label map and use only the defined classes.

02 · LOCALIZEDraw a tight box

Cover the visible object, not its cast shadow.

03 · RECORDKeep instances separate

Assign a stable ID and preserve original pixel coordinates.

04 · VALIDATERun the audit

Check file references, classes, IDs and coordinate bounds.
